### Description

The convergence of blockchain and 5G security presents an opportunity to redefine authentication mechanisms within the core network. Traditional OAuth 2.0 authorization mechanisms in 5G rely on centralized components such as the Network Repository Function (NRF) to verify NF identities and issue access tokens. This introduces risks, including single points of failure, insider threats, and identity spoofing.
This research explores a decentralized trust model for NF authentication using blockchain-based OAuth 2.0 authorization. The study will analyze the feasibility of leveraging blockchain smart contracts for secure, verifiable access token issuance, ensuring immutable NF identity records and distributed validation. By integrating blockchain with an open-source 5G core, the project aims to enhance security, mitigate attack vectors, and reduce dependency on centralized trust anchors.

Key aspects include:
- Designing a blockchain-based access token mechanism for NF authentication.
- Integrating blockchain with open-source 5G core solutions.
- Evaluating performance overhead and security benefits compared to traditional methods.


### Learning Objectives

- Deepen understanding of decentralized authentication models and their application in 5G core security.
- Gain hands-on experience integrating blockchain with open-source 5G core networks.
- Learn to develop and optimize smart contracts for secure, distributed authorization.
- Analyze security and performance trade-offs in blockchain-based NF authentication.


### Expected Outcome and Deliverables

- Design and prototype of a blockchain-integrated OAuth 2.0 authorization mechanism for NF authentication.
- Implementation and testing of the system using an open-source 5G core solution.
- Performance benchmarking against traditional NRF-based authorization models.
- Security evaluation covering resilience to identity spoofing, insider attacks, and token misuse.
- Documentation and research insights into blockchain-driven 5G security enhancements.


### Relation to LF Decentralized Trust and impact on the community

This project aligns with LF Decentralized Trust by exploring blockchain as a foundational component in securing NF authentication and authorization in 5G core networks. By replacing centralized trust points with decentralized validation, the research contributes to building a more resilient, tamper-resistant authentication model. The findings can guide future blockchain applications in **telecom security** and influence standardization efforts in decentralized 5G trust frameworks.

Research

### Description

This project aims to integrate Hyperledger Aries, Indy, and AnonCreds with Layer 2 (L2) rollups (e.g., zkSync) to create a scalable, cost-efficient, and privacy-preserving decentralized identity (DID) system. This project will offload the most expensive part of identity verification—zero-knowledge proof (ZKP) generation and verification in AnonCreds— to L2, reducing the computational and gas costs of verifiable credential (VC) issuance and authentication. By using L2 rollups for credential commitments, revocation registries, and consent management, the project ensures fast, low-cost transactions while periodically anchoring state proofs to Ethereum (L1) for auditability and trust. This system will enable decentralized authentication for dApps, and Web3 platforms without relying on centralized identity providers.

Hyperledger-based identity systems, such as Aries, Indy, and AnonCreds, are widely used for verifiable credential issuance and privacy-preserving authentication but face challenges with scalability, interoperability with public blockchains, and efficient on-chain verification. This project addresses these issues by leveraging L2 rollups (e.g. zkSync) to store credential commitments, manage revocation registries, and execute privacy-preserving verifications on-chain. The implementation will include deploying L2 smart contracts for DID resolution and ZKP validation, integrating with Hyperledger Aries agents for off-chain credential exchange, and ensuring cross-chain interoperability with Ethereum and other Web3 applications. The result will be a scalable, interoperable, and cost-effective identity solution that bridges Hyperledger identity frameworks with public blockchain ecosystems.


### Learning Objectives

**Decentralized Identity & Verifiable Credentials:** Gain hands-on experience with Hyperledger Aries, Indy, and AnonCreds, learning how DIDs, verifiable credentials (VCs), and zero-knowledge proofs (ZKPs) work in decentralized identity systems.

**Layer 2 Rollups & Smart Contract Development**: Learn how to deploy and interact with smart contracts on zkSync (L2 rollup) to handle DID resolution, credential revocation, and ZKP-based verification, improving scalability and cost efficiency.

**Privacy-Preserving Authentication & ZKPs**: Understand how zero-knowledge proofs (ZKPs) enable selective disclosure and privacy-preserving identity verification, and implement ZKP-based credential validation on L2.

**Cross-Platform Integration & Web3 Identity Interoperability**: Work on integrating Hyperledger-based identity frameworks with Ethereum and other Web3 applications, ensuring smooth cross-chain identity verification.

**Open Source Collaboration & Contribution**: Gain experience in collaborating with open-source communities, contributing to Hyperledger and Ethereum ecosystem projects, and improving technical documentation, issue tracking, and code quality.


### Expected Outcome and Deliverables

- An open-source implementation of a decentralized identity framework integrating Hyperledger Aries, Indy, and AnonCreds with L2 rollup (e.g. zkSync) for scalable and privacy-preserving verifiable credentials.
- Smart contracts deployed on L2 rollup to support DID resolution, credential storage, revocation registries, and ZKP-based authentication.
- Evaluation report detailing the performance, cost efficiency, and scalability benefits of running identity operations on L2 compared to traditional approaches.
- Demonstrated use case scenarios, showcasing how this identity solution enhances scalability, privacy, and cost savings while maintaining interoperability with Ethereum (L1).
- Identification of potential challenges, trade-offs, and areas for future improvement in Hyperledger-based identity systems integrated with L2 rollups.

Deliverables:

- Smart Contracts on L2: Implement and deploy DID registry, credential verification, and revocation contracts to enable identity operations on L2.
- Integration with Hyperledger Aries & Indy: Develop middleware or APIs to connect Aries agents and Indy identity registries with zkSync for on-chain credential management.
- Evaluation Report & Benchmarking: Assess the scalability, cost efficiency, and ZKP performance of the solution compared to traditional Hyperledger identity frameworks.
- Project Demo Video: Showcase the framework’s functionality through real-world use case demonstrations and step-by-step walkthroughs.
- Technical Documentation & Open Source Code Repository: Provide detailed documentation, including installation guides, APIs, and integration instructions, ensuring long-term community adoption and contribution.


### Relation to LF Decentralized Trust and impact on the community

This project directly contributes to LF Decentralized Trust initiatives by integrating Hyperledger Aries, Indy, and AnonCreds with Layer 2 rollup to improve the scalability, cost-efficiency, and privacy of decentralized identity (DID) systems. It aligns with ongoing efforts in Hyperledger and Ethereum ecosystems to enhance decentralized identity solutions while ensuring interoperability with public blockchains.

Related LF Decentralized Trust Projects & Labs:

- Hyperledger Aries – Enhancing Aries agents with support for zkSync-based DID verification and credential management.
- Hyperledger Indy – Improving scalability by enabling off-chain credential issuance with on-chain verification and revocation on L2 rollups.
- Hyperledger AnonCreds – Leveraging L2 (e.g., zkSync’s) ZKP-based verification to enhance privacy-preserving credential authentication at a lower cost.

**Blockchain Development**: Experience with Ethereum, Layer 2 rollups (zkSync, StarkNet, Arbitrum, or Optimism), and smart contract development using Solidity

### Description

Fabric Private Chaincode (FPC) leverages modern Confidential Computing technology, such as Intel SGX, to enhance the protection of chaincode and their data while executed at the endorsing peers. Client applications interact with their private chaincode via the FPC Client SDK, which is responsible to encrypt and authenticate the invocation arguments before being sent to the endorsing peers. Currently chaincodes can be developed in C++ or Golang.

The Hyperledger Labs CC-Tools library offers several features that facilitate the journey of learning, development and deployment of chaincode for Hyperledger Fabric in Golang.

Both projects have been integrated successfully during the Hyperledger Mentorship program 2024, allowing for the development of chaincodes leveraging the privacy aspects of FPC and the fast and easy development of CC-Tools. This mentorship proposal builds on top of the previous project.

The goal of this mentorship project is to:
- develop a demo application that showcases the benefits of FPC and CC-Tools;
- identify a demo use case (i.e., digital asset exchange) that comes with privacy-sensitive requirements, which can be covered by FPC;
- analyze the applicability of using the Token Taxonomy Framework to define the selected digital asset;
- implement a prototype application with CC-Tools, developing the token taxonomy if appropriate;
- produce documentation that explains the application and how it can be used.


### Learning Objectives

- Deep dive into Hyperledger Fabric, in particular, Fabric Private Chaincode using Confidential Computing, and the Hyperledger Lab CC-Tools.
- Experience an active open-source community.
- Mastering open-source workflow.

### Expected Outcome and Deliverables

- Demo application that showcases the benefits of FPC and CC-Tools.

### Description


Blockchain technology, originally developed for TCP/IP-based networks, has emerged as a transformative force across various industries, attributable to its decentralized, immutable, and highly secure ledger capabilities. Nevertheless, the advent of new applications in non-TCP/IP environments, such as satellite links, mesh networks, and IoT protocols (e.g. LoRaWAN), necessitate tailored adaptations to facilitate the effective integration of blockchain. This proposal presents a testing framework aimed at assessing blockchain performance in these non-TCP/IP contexts, with a particular emphasis on its application in **satellite communication**.

Satellite communication operates under unique constraints, including high latency, intermittent connectivity, limited bandwidth, and energy efficiency concerns. Evaluating blockchain performance in such an environment requires accurate simulation of these real-world conditions to determine feasibility and optimize implementation. It is imperative to establish a well-designed testing framework that emphasizes security, performance, and fault tolerance to validate the feasibility of blockchain in these domains.

The proposed testing framework is designed to evaluate the performance of blockchain technology in non-TCP/IP environments, such as satellite communication. This will be achieved by integrating Hyperledger Fabric with network simulation and real-time monitoring tools. We will utilize **open-source NS3 with the SNS3 module** to emulate communication protocols and assess blockchain behaviour in alternative networking scenarios. Furthermore, real-time visualization, performance monitoring, and analysis will be facilitated by integrating Grafana, Prometheus, and NetAnim. This will ensure a thorough examination of blockchain synchronization, latency, and security under constrained network conditions. Overall, this framework aims to provide a structured approach to studying the adaptability and efficiency of blockchain technology in non-traditional communication environments.


### Learning Objectives

- Understand the potential of blockchain beyond traditional internet-based networks such as satellite communication environments, analyze the challenges of deploying blockchain in non-TCP/IP environments, and learn how environmental constraints, such as limited bandwidth, intermittent connectivity, and scalability issues, affect blockchain implementation.
- Develop skills in NS3 simulation to model and test blockchain performance under various network conditions and scenarios.
- Examine security implications in constrained environments with operating blockchain in isolated or resource-limited environments and explore appropriate consensus mechanisms.
- Apply benchmarking tools like Hyperledger Fabric and Caliper to evaluate blockchain applications' performance, scalability, and security under non-TCP/IP conditions.
- Assess the impact of latency, bandwidth, and energy efficiency and explore those constraints in edge environments that affect blockchain performance.
- Develop automated scripts for continuous testing, benchmarking, and reporting to streamline blockchain testing.


### Expected Outcome and Deliverables

- A comprehensive testing framework for blockchain in non-TCP/IP environments that incorporates both Hyperledger Fabric and NS3 simulations to evaluate blockchain's performance, security, and scalability.
- Develop automation tools for the framework where continuous testing, benchmarking, and system monitoring can be carried out automatically.
- Research and analyze the generated performance reports to provide actionable recommendations for blockchain applications operating outside of traditional TCP/IP settings.


### Relation to LF Decentralized Trust and impact on the community


This project aims to examine the application of blockchain technology in unconventional networks where traditional decentralized models may prove inadequate. It seeks to extend the principles of decentralization into new domains by investigating the functionality of blockchain in environments such as satellite communications. The research will establish a foundational framework for blockchain-based systems in contexts where global internet infrastructure may be lacking. 

The outcomes of this study will empower organizations to incorporate blockchain into emerging technologies, thereby promoting innovation across various industries, including aerospace, and facilitating the development of decentralized applications that function independently of conventional internet protocols.  Additionally, this project will strengthen the LF Decentralized Trust ecosystem by integrating **Hyperledger Fabric** with **open-source NS-3 network simulator**, advancing blockchain research in non-traditional domains.


### Recommended Skills

- Familiarity with Hyperledger Fabric and other blockchain platforms and using NS3 to model and simulate real-world network scenarios.
- Strong programming skills, particularly in Python or C++ and experience with the Linux environment.
- Knowledge of tools like Hyperledger Caliper and experience in performance benchmarking, especially in testing blockchain under different network conditions.

Research

### Description

**Project Scope and Objective**
This mentorship program aims to conduct a comprehensive empirical study of cross-chain bridges, focusing on security, performance, scalability, and cost of protocols. Cross-chain bridges are fundamental to blockchain interoperability, enabling seamless asset transfers between distributed ledger technologies (DLTs). However, their security vulnerabilities have led to over $2 billion in losses, highlighting the urgent need for rigorous analysis. This project seeks to empirically evaluate industry-standard bridges, both within Hyperledger technologies and public blockchains, to develop performance benchmarks and security insights.

**Problem Statement and Opportunity**
Despite existing research on blockchain interoperability, there is a lack of empirical studies comparing cross-chain bridge solutions. Previous efforts, including Hyperledger mentorships, have focused on specific implementations, but a broader industry-wide comparison remains unexplored. The increasing adoption of cross-chain bridges necessitates a standardized approach to assess their efficiency, cost, and security risks. By addressing this gap, the project will provide valuable insights for developers, enterprises, and the wider blockchain community to make informed decisions about bridge selection and improvements.

**Implementation Path**

1. Research: Identify key interoperability solutions, industry and Hyperledger-specific bridges, and establish relevant performance metrics (e.g., latency, throughput, transaction costs).

2. Test Environment Setup: Deploy multiple DLT networks, integrate cross-chain solutions, and define standardized benchmarking tests.

3. Empirical Evaluation: Conduct data collection and performance tests under different scenarios, measuring security resilience, scalability, operational efficiency, and protocol cost.

4. Analysis & Reporting: Interpret the collected data, compare solutions, and identify areas for optimization.

5. Academic Paper: Produce and publish an academic paper to share findings with the Hyperledger community and the broader blockchain ecosystem.

### Learning Objectives

- Gain hands-on experience in contributing to an open-source project, including testing, documentation, and best practices for collaborative development within the Hyperledger community
- Develop a deep understanding of cross-chain interoperability protocols
- Enhance technical writing skills by documenting findings in an academic paper, contributing to both industry and academic discussions on blockchain interoperability
- Develop research, coding, and data analysis skills by analyzing large scale datasets of cross-chain transactions


### Expected Outcome and Deliverables

A comprehensive report detailing performance comparisons of various cross-chain bridges based on latency, throughput, and cost metrics.

A reusable framework for benchmarking interoperability solutions, including scripts and configurations for setting up test environments.

Clear documentation on the benchmarking methodology, tools used, and steps to reproduce experiments, ensuring the project's long-term usability.

A research paper summarizing key findings, which may be submitted to an academic conference or industry publication to contribute to blockchain interoperability research.

Code contributions or improvements to existing Hyperledger interoperability project (Cacti), integrating benchmarking insights and recommendations.

### Relation to LF Decentralized Trust and impact on the community

**Background**: Recently, global governments have imposed legislation focused on requiring business entities to perform greenhouse gas (GHG) emission accounting in their supply chains as a requirement for trade. In addition, governments are pushing supply chains to become net-zero for GHG emissions. Other climate change related legislation impacting global supply chain GHG emission accounting and reduction are: 
•	Governments are attaching GHG emissions accounting regulations on supply chains importing goods into their countries.
•	Consumers and corporate customers are demanding sustainability in their business practices focused on GHG reduction.

The Digital Twin is to identically represent the physical supply chain with the ability to track the supply chain’s GHG emissions in real time.
